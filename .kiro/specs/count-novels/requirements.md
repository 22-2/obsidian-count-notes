# 要件定義書

## はじめに

count-novelsは、Obsidianで小説などを執筆するユーザー向けの執筆進捗トラッカープラグインです。日々の執筆量（文字数）を自動集計し、グラフで可視化することで、執筆のモチベーション維持を支援します。シンプルで使いやすいMVP（最小実行可能製品）として開発します。

## 要件

### 要件1：設定管理

**ユーザーストーリー：** 執筆者として、集計対象のタグを指定できるようにしたい。そうすることで、小説執筆用のノートだけを対象にして正確な執筆量を把握できる。

#### 受入基準

1. WHEN ユーザーがプラグイン設定画面を開く THEN システムは集計対象タグの設定フィールドを表示する
2. WHEN ユーザーがタグ名を入力して保存する THEN システムはそのタグをdata.jsonに保存する
3. IF タグが設定されていない場合 THEN システムはデフォルトで"novel"タグを使用する

### 要件2：文字数集計とデータ収集

**ユーザーストーリー：** 執筆者として、執筆量が自動的に集計されるようにしたい。そうすることで、手動で文字数を数える手間を省き、執筆に集中できる。

#### 受入基準

1. WHEN Obsidianが起動する THEN システムは指定タグを持つ全ファイルの合計文字数を計算する
2. WHEN 10分経過する THEN システムは再度合計文字数を計算し、前回との差分を記録する
3. WHEN 差分が計算される THEN システムはその日の執筆量として日付と共にdata.jsonに保存する
4. WHEN 集計が完了する THEN システムは現在の合計文字数を次回比較用として保存する
5. IF 差分がマイナスの場合 THEN システムはマイナス値をそのまま記録する（推敲による削除を追跡するため）

### 要件3：統計ビューの表示

**ユーザーストーリー：** 執筆者として、執筆進捗を視覚的に確認できるビューが欲しい。そうすることで、自分の執筆パターンを把握し、モチベーションを維持できる。

#### 受入基準

1. WHEN ユーザーがサイドバーのプラグインアイコンをクリックする THEN システムは統計ビューを開く
2. WHEN 統計ビューが開かれる THEN システムは今月の合計執筆文字数を表示する
3. WHEN 統計ビューが開かれる THEN システムは継続日数（ストリーク）を表示する
4. WHEN 統計ビューが開かれる THEN システムは月間バーグラフを表示する
5. IF データが存在しない場合 THEN システムは「データがありません」メッセージを表示する

### 要件4：グラフ表示機能

**ユーザーストーリー：** 執筆者として、日々の執筆量をグラフで確認したい。そうすることで、執筆の傾向や成果を視覚的に把握できる。

#### 受入基準

1. WHEN 統計ビューが表示される THEN システムはChart.jsを使用してバーグラフを描画する
2. WHEN グラフが描画される THEN X軸には日付（1日、2日、3日...）を表示する
3. WHEN グラフが描画される THEN Y軸には文字数を表示する
4. WHEN グラフが描画される THEN 各日の執筆文字数をバーで表示する
5. WHEN マイナス値がある場合 THEN システムは削除された文字数として異なる色で表示する
6. WHEN 月が変わる THEN システムは新しい月のデータでグラフを更新する

### 要件5：データ永続化

**ユーザーストーリー：** 執筆者として、執筆データが確実に保存されるようにしたい。そうすることで、長期間の執筆進捗を追跡できる。

#### 受入基準

1. WHEN 執筆データが更新される THEN システムはObsidian標準のsaveData APIを使用してdata.jsonに保存する
2. WHEN プラグインが読み込まれる THEN システムはloadData APIを使用してdata.jsonからデータを読み込む
3. WHEN データ構造が変更される THEN システムは後方互換性を維持する
4. IF data.jsonが存在しない場合 THEN システムは初期データ構造を作成する
5. IF データの読み込みに失敗した場合 THEN システムはエラーログを出力し、初期状態で動作する

### 要件6：継続日数計算

**ユーザーストーリー：** 執筆者として、連続して執筆した日数を確認したい。そうすることで、執筆習慣の維持に対するモチベーションを得られる。

#### 受入基準

1. WHEN 継続日数が計算される THEN システムは1文字以上執筆した日を「執筆日」とカウントする
2. WHEN 継続日数が計算される THEN システムは今日から遡って連続する執筆日数を計算する
3. WHEN 執筆しなかった日がある THEN システムは継続日数をリセットする
4. WHEN 今日まだ執筆していない場合 THEN システムは昨日までの継続日数を表示する
5. IF 執筆データが1日もない場合 THEN システムは継続日数を0として表示する
